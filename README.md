# GraphMe — 记忆星云可视化系统

> **记忆不是孤岛，而是星座——让每一颗记忆原子在时空中相互关联，照亮那些深埋已久的高价值时刻。**

GraphMe 是一款面向 Agent 的**长期记忆管理与 3D 可视化系统**。它将结构化的多维向量空间转化为用户可感知、可探索、可管理的**3D 记忆星云**，解决 Agent "记忆黑盒化"的核心痛点。

---

## 核心概念

### 双层记忆架构

| 原始记忆 (Raw Memory) | 洞察记忆 (Insight Memory) |
|---|---|
| 传感器采集 / 用户手动添加 | 从原始记忆聚类推理生成 |
| "发生过的事" | "被发现的模式/趋势/信念" |
| 事实性的，不可推翻 | 概率性的，随新数据演进 |
| 只能被删除 | 只能被新版本替代（旧版本保留为历史） |

### 记忆图 (Memory Graph)

所有洞察记忆的集合构成用户的"记忆图谱"——它随时间**演变**：
- 新原始记忆加入 → 重新推理 → 生成新版本洞察记忆 = **成长**
- 新数据与旧洞察一致 → 生长表现为"印证加深"（confidence 上升）
- 新数据与旧洞察矛盾 → 生长表现为"自我进化"（旧版本保留为历史）

### 10 维记忆剖面

每条记忆原子携带完整 10 维剖面（49 个子维度）：
时间 · 空间 · 社交 · 情绪 · 活动 · 感知 · 语义 · 价值 · 叙事 · 机器人状态

## 功能特性

- **3D 记忆星云** — Three.js 驱动的粒子云可视化，支持旋转、缩放、聚类
- **维度切换器** — 家庭/学习/情绪/全局四视图，按维度过滤记忆
- **记忆导航** — 左侧分类侧栏，面包屑导航，点击即高亮对应 cluster
- **洞察记忆** — 金色光环标注 AI 推理生成的洞察，含置信度、版本历史和依据溯源
- **CRUD 面板** — 记忆原子的增/删/改/查，支持文本字段编辑
- **Chat Assistant** — 预设 Q&A，答案可链接到相关记忆
- **一键演示** — 7 步自动巡航，支持上一步/下一步手动控制
- **图例系统** — 颜色、形状、连线类型的图例说明
- **原始/洞察记忆分离展示** — 可选择隐藏任一类型，专注查看
- **导航折叠** — 侧栏可折叠为图标模式，星云展示空间最大化

## 快速开始

### 前置要求

- Node.js >= 18
- npm >= 9

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/wukun2005-gif/GraphMe.git
cd GraphMe

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

浏览器打开 `http://localhost:5173`。

## 设计理念

### 心理学渊源

- **巴特莱特的"图式"理论** (1932)：记忆不是回放，是用已有心理框架重构
- **皮亚杰的"同化与顺应"**：新经验要么被同化进旧图式，要么迫使图式修正
- **鲍尔比的"内部工作模型"**：人从互动中构建关于自我和他人的心理模型
- **弗里斯顿的"预测加工"**：大脑维护一个关于世界的内部生成模型，预测失败时更新

### 可视化信任

Agent 的记忆一直是个"黑盒"——用户不知道设备记住了什么。GraphMe 让用户第一次真正"看到"记忆的全貌，建立可视化信任。
