## 为什么要做 GraphMe？

AI 正以前所未有的速度渗透到我们的日常生活——智能音箱记得你的音乐偏好，陪伴机器人知道你孩子的名字，学习助手了解你的知识盲区。但这些 AI agent 记住的东西，对用户来说始终是一个**黑盒**。

你不知道 agent 记住了什么、不知道它为什么会做出某个回应、不知道哪些记忆该留着、哪些该删掉。更糟的是，不同 agent 应用之间的记忆是天然隔离的——你的陪伴机器人和学习助手各自存储了关于你的碎片，却从未被整合成一幅完整的"你"的画像。

**GraphMe 想解决的核心问题：把 AI agent 的"记忆黑盒"打开，变成用户可感知、可探索、可管理的数字记忆资产。**

## 竞品调研与差异化定位

### 调研范围

我们调研了当前市场上与"个人记忆 / 知识管理 / 可视化分析"相关的四类产品：

| 类别 | 代表产品形态 | 核心能力 | 与 GraphMe 的关系 |
|---|---|---|---|
| **全功能工作台** | 以文档、数据库、页面为基本单元的一体化协作工具 | 结构化信息管理、多视图切换、团队协作 | 面向通用信息组织，不区分"记忆"和"笔记"，缺乏 AI 推理层 |
| **双向链接笔记** | 以 Markdown 文件为基础、支持 `[[双向链接]]` 和关系图谱的本地化知识库 | 原子化笔记、反向链接、2D 图谱 | 关系图谱仅展示"你手动建立的链接"，不做语义聚类或 AI 推断 |
| **可视化白板** | 以无限画布 + 卡片为交互范式的思维整理工具 | 自由布局、空间思维、头脑风暴 | 侧重手动组织，不处理 AI agent 产生的记忆数据，无自动聚类能力 |
| **AI 记忆助手** | 基于 LLM 的个人伴侣 / 笔记应用，自动记录对话或屏幕内容 | 被动记忆记录、时间线回放、自然语言检索 | 记忆以时间线或列表展示，缺少空间化、多维度的记忆管理界面 |

### 核心发现：市场缺口

调研后我们发现，上述四类产品各自解决了一部分问题，但存在三个共同的盲区：

1. **记忆 ≠ 笔记。** 现有工具把用户"主动写下来的东西"和"AI agent 自动记住的东西"混为一谈。前者是你想整理的知识，后者是 agent 在交互中被动积累的关于你的认知碎片——它们的性质、可信度、管理方式完全不同。

2. **有链接，无推理。** 双向链接笔记的图谱很好看，但它只反映"你手动创建了链接"这个事实。图谱不会告诉你"这两件事虽然你没关联，但 AI 发现它们有深层模式"。

3. **有列表，无空间。** AI 记忆助手把你的记忆排成时间线或搜索结果列表，但人类的记忆不是线性的——它是多维的、空间的、关联的。把记忆放回空间中是理解它们的前提。

### GraphMe 的差异化优势

基于以上发现，GraphMe 在 Demo 中重点验证以下五个差异化方向：

#### 差异化 1：记忆分层——Raw vs Insight 双层架构

> **竞品现状：** 大多数工具只管理一层"条目"（文档 / 笔记 / 卡片），不区分原始事实和推导结论。
>
> **GraphMe 的做法：** 将记忆分为 **原始记忆（Raw Memory）** 和 **洞察记忆（Insight Memory）**。原始记忆是"发生过的事"（不可推翻，只能删除），洞察记忆是"从多段原始记忆中推理出的模式/趋势/信念"（概率性的，随新数据演进，旧版本保留为历史）。
>
> **Demo 功能映射：**
> - 3D 星云中金色圆环 = 洞察记忆，彩色粒子 = 原始记忆，一眼区分层级
> - 详情面板中洞察记忆展示版本链（`v1 → v2 → v3`），可追溯推理演进过程
> - 新增原始记忆时，关联洞察自动更新置信度和版本号

#### 差异化 2：语义空间可视化——3D 记忆星云

> **竞品现状：** 图谱类工具多为 2D 力导向布局，关系仅基于显式链接；AI 记忆助手以列表 / 时间线展示。
>
> **GraphMe 的做法：** 将记忆的向量语义距离映射为 3D 空间距离——语义越近的记忆在空间中越靠近，自动形成簇群。不是"画一个好看的图"，而是让你用空间直觉理解记忆关系。
>
> **Demo 功能映射：**
> - 3D 星云场景，支持缩放 / 旋转 / 拖拽
> - 粒子颜色按情绪维度着色（快乐=金黄、悲伤=蓝色、好奇=青色等），一眼感知情绪分布
> - 点击粒子弹出详情面板，查看该记忆的 10 维度完整数据

#### 差异化 3：多维度视图 + 分类筛选——两套独立的导航体系

> **竞品现状：** 大部分工具提供单一视角（时间线、列表、画布），切换视角需要重新组织数据。
>
> **GraphMe 的做法：** GraphMe 提供了导航机制，解决不同的问题：

**左侧分类导航栏（内容过滤）**

按记忆的发生地点（`spatial.placeType`）过滤星空中的粒子。「家庭生活」只显示发生在家里的记忆，「学习与成长」只显示在学校/图书馆的记忆。选择子分类（如「编程学习」）会进一步缩小范围。

> **Demo 功能映射：**
> - 侧边导航栏按「家庭生活 / 学习与成长 / 社交与情感 / 兴趣与探索」分类
> - 每个分类下还有子分类（如「编程学习」「数学学习」「阅读习惯」）
> - 选择分类后，星云中只显示符合条件的粒子，其余隐藏

#### 差异化 4：记忆价值量化——CQI 评分与遗忘预警

> **竞品现状：** 通用工具不评估记忆/笔记的"价值"，所有内容一视同仁。
>
> **GraphMe 的做法：** 引入 **CQI（Comprehensive Quality Index，综合质量指数）**，从重要性、情感强度、访问频率、隐私等级等多个维度自动为每条记忆打分。同时识别"遗忘风险"——长期未访问但高价值的记忆。
>
> **Demo 功能映射：**
> - 价值看板（Value Dashboard）：Top 5 高价值记忆排行
> - 遗忘风险预警：按高 / 中 / 低三档标注风险等级
> - 记忆详情中展示 `importance` 和 `cqi` 数值

#### 差异化 5：对话即导航——记忆链接打通 Chat ↔ 星云

> **竞品现状：** AI 对话工具的回复中提及过去信息，但用户无法追溯"这句话基于哪段记忆"。
>
> **GraphMe 的做法：** 在对话回复中嵌入可点击的记忆链接，点击后直接跳转到对应记忆在 3D 星云中的位置并展开详情。实现"对话 → 记忆 → 空间"的闭环导航。
>
> **Demo 功能映射：**
> - Chat Panel：预设 Q&A 模拟 AI 基于记忆网络的对话
> - 回复中包含 `🔗 查看相关记忆` 链接，点击自动定位星云粒子
> - 一键 Demo 模式（90 秒）展示完整工作流：星云探索 → 维度切换 → 详情查看 → 价值看板 → Chat 对话 → 记忆链接跳转

### 差异化总结

| 维度 | 通用工具 | GraphMe |
|---|---|---|
| **记忆模型** | 单层（笔记=记忆） | 双层（Raw + Insight） |
| **可视化** | 2D 图谱 / 列表 / 时间线 | 3D 语义空间 + 情绪着色 |
| **视角** | 单一视角 | 4 维度空间重排（顶部切换）+ 分类过滤（左侧导航），可组合使用 |
| **价值量化** | 无 | CQI 评分 + 遗忘预警 |
| **AI 可解释性** | 黑盒 | 对话记忆链接 → 空间追溯 |
| **数据模型** | 扁平字段 | 10 维度（时间/空间/社交/情绪/活动/感官/语义/价值/叙事/Agent状态） |

## 核心思路

GraphMe 的名字来源于 **Graph（图谱）+ Me（我）**——你的记忆不是散落的点，而是相互关联的认知网络。

### 双层记忆架构

GraphMe 将记忆分为两个层次：

| | 原始记忆（Raw Memory） | 洞察记忆（Insight Memory） |
|---|---|---|
| **是什么** | 用户直接输入或系统自动记录的事件 | 从原始记忆聚类推理生成的高阶认知 |
| **好比** | "发生过的事" | "被发现的模式 / 趋势 / 信念" |
| **性质** | 事实性的，不可推翻 | 概率性的，随新数据演进 |
| **操作** | 只能被删除 | 只能被新版本替代（旧版本保留为历史） |

当新的原始记忆加入时，系统会重新推理并生成新版本的洞察记忆——这正是心理学中**巴特莱特的"图式"理论**和**皮亚杰的"同化与顺应"**在数字记忆领域的映射：人的记忆不是简单回放，而是用已有心理框架不断重构。GraphMe 让这个动态过程变得可见。

### 从向量空间到 3D 记忆星云

AI 的记忆天然存在于多维向量空间中。GraphMe 不做炫技的视觉效果，而是让你直观感受到向量空间中那些天然存在的关系：

- **语义距离（Semantic Distance）→ 粒子的远与近**——越相关的记忆越靠近
- **聚类（Clustering）→ 簇群的形成与重叠**——相似记忆自动聚集成簇
- **分类（Classification）→ 粒子的颜色与归类**——不同类别的记忆用颜色区分

你拖拽、旋转、缩放这个 3D 记忆星云时，操控的不只是视觉效果，而是对向量空间关系的物理直觉。

## 快速开始

### 前置要求

- Node.js >= 18
- npm >= 9

### 安装与运行

```bash
git clone https://github.com/wukun2005-gif/GraphMe.git
cd GraphMe
npm install
npm run dev
```

浏览器打开 `http://localhost:5173` 即可看到 3D 记忆星云。
